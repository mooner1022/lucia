# 관리 화면 디자인 언어 (결정 0062)

관리 화면의 모습은 Lucia의 캐릭터 디자인 시트에서 온다. 이 문서는 시트의 무엇을 화면의 무엇으로 옮겼는지, 부품을 고치거나 새로 만들 때 무엇을 지켜야 하는지를 적는다. 화면을 짜는 법은 `pages.md`, 데몬이 주는 값은 `derived.md`에 있다.

## 1. 바탕 생각

시트의 인상은 "흰 옷을 입은 조용한 사람"이다. 대부분이 흰색과 옅은 푸른빛이고, 쪽빛은 깃·허리띠에만, 금색은 매듭과 자수 선에만 있다. 화면도 같은 비율을 지킨다.

| 몫 | 시트 | 화면 |
| --- | --- | --- |
| 일곱 | 흰 저고리, 머리카락 | 카드와 바탕(`--surface`, `--bg`) |
| 둘 | 치마의 푸른 번짐, 눈동자 | 본문 위쪽의 하늘 번짐, 사이드바 아래쪽의 치맛단(`--sky`, `--wash`, `--hem`) |
| 하나 | 깃·허리띠·리본의 쪽빛 | 띠: 구역 제목, 지금 화면 표시, 주된 단추, 좁은 화면의 위 막대(`--band`, `--accent`) |
| 조금 | 매듭·자수의 금선 | 띠 안쪽의 한 줄, 제목 아래의 맺음 줄, 작은 꽃 표시(`--band-line`, `--gold`) |

성격(차분하고 온화하며 다정하다)은 이렇게 옮긴다.

- **차분하다**: 한 화면에 쪽빛 띠 말고 눈을 끄는 것을 두지 않는다. 경고색은 살펴야 할 때만 나온다. 조작 요소의 움직임은 색이 바뀌는 0.15초가 전부다.
- **부드럽다**: 모서리는 둥글고, 단추·배지·띠는 알약 꼴이다. 테두리는 옅은 푸른 실선 한 줄, 그림자는 푸른빛이 도는 옅은 것 하나다.
- **감성은 바탕과 가장자리에**: 꽃과 글귀는 화면의 가장자리(사이드바 아래, 로그인 바탕, 맺음)에, 흩날리는 꽃잎은 카드 뒤의 바탕에만 둔다. 표·폼·목록 같은 일하는 자리에는 장식을 넣지 않는다. 카드 안은 번짐 없이 흰 면이다.

## 2. 시트의 요소 → 화면의 자리

| 시트 | 화면 | 어디 |
| --- | --- | --- |
| 이름표(쪽빛 바탕, 흰 글, 꽃, 겹선) | 구역 제목의 띠: 카드의 왼쪽 가장자리에서 나온다 | `Section` |
| 허리띠와 매듭 | 지금 화면 표시(쪽빛 알약, 안쪽 금선), 주된 단추, 탭의 지금 칸 | `Shell`, `Button`, `Tabs` |
| 치마(위는 희고 단으로 갈수록 푸르며 흰 꽃무늬) | 사이드바와 펼침 메뉴의 바탕, 로그인 화면의 바탕 | `Shell`, `Solo` |
| 머리의 꽃, 치마의 꽃잎 | 바탕에 흩날리는 연한 꽃잎(본문과 로그인 화면) | `Petals` |
| 꽃 문양·머리의 꽃 | 이름 표식(쪽빛 원 안의 흰 꽃), 제목 아래 맺음 줄, 소제목 앞, 맺음 | `Shell`, `Solo`, `Page`, `base.css` |
| 이름의 명조 글씨 | 화면 제목, 이름, 로그인, 맺음 글귀 | `--font-display` |
| 머리말 글귀 | 로그인 카드와 본문 맺음의 한 줄 | `Solo`, `Shell` |
| 구름 문양(소매 자수) | 쓰지 않는다(처음에는 본문 오른쪽 위에 선 그림으로 뒀다가, 사용자 지시로 꽃잎으로 바꿨다) | |
| 뿔, 깃털, 술 | 쓰지 않는다(작게 그리면 알아볼 수 없다) | |

화면에 적는 이름은 사용자가 정한 이름이다(기본 "Lucia", 결정 0064. 초기 설정 화면에서 정한다). 시트의 이름은 화면에 쓰지 않는다. 이름은 길 수 있으니(24자까지) 머리글은 줄을 바꾸고 끊을 곳 없는 긴 이름은 어디서든 끊는다.

## 3. 색

색은 `src/ui/tokens.css`에서만 정한다. 부품은 토큰만 쓴다(고정 색을 쓰면 `tests/a11y.test.ts`가 막는다). 섞어야 하면 `color-mix(in srgb, var(--토큰) 30%, transparent)`를 쓴다.

| 토큰 | 뜻 | 쓰는 곳 |
| --- | --- | --- |
| `--bg`, `--surface`, `--surface-2`, `--surface-3` | 바탕, 카드, 한 단 들어간 면, 눌린 면 | 모든 부품 |
| `--border`, `--border-strong` | 옅은 푸른 실선, 입력·단추의 경계(3:1) | |
| `--text`, `--text-2`, `--text-3` | 먹빛 쪽색 글, 흐린 글, 도움말 | |
| `--accent`, `--accent-hover`, `--accent-soft`, `--accent-text`, `--on-accent` | 쪽빛(단추, 링크, 고른 것) | |
| `--band`, `--band-2`, `--on-band`, `--on-band-2`, `--band-line` | 띠의 그라데이션 양 끝, 띠 위의 글, 띠 위의 곁글, 띠 위의 금선·아이콘 | `Section`, `Shell`, `Tabs`, `Step` |
| `--gold` | 밝은 면 위의 금선(장식) | `Page`, `base.css` |
| `--sky`, `--wash`, `--hem`, `--petal`, `--glow` | 하늘, 번짐, 치맛단, 치맛단의 꽃잎, 빛 | `Shell`, `Solo` |
| `--drift` | 흩날리는 꽃잎 | `Petals` |
| `--ok`, `--warn`, `--bad`, `--info`, `--muted`과 각각의 `-soft` | 결(비취, 호박, 연지, 하늘, 회청) | 배지, 안내, 점 |
| `--shadow-1`, `--shadow-2`, `--shadow-band` | 카드, 떠 있는 창, 띠 | |
| `--drift-alpha`, `--petal-alpha` | 흩날리는 꽃잎과 치맛단 꽃의 진하기(판마다 다르다) | |

지킬 것:

- **띠 위에는 `--on-band`, `--on-band-2`, `--band-line`만 올린다.** 띠의 그라데이션은 `linear-gradient(120deg, var(--band), var(--band-2))`로 통일한다.
- **금색은 글과 입력 경계에 쓰지 않는다.** 대비가 모자라고, 카드 테두리로 쓰면 경고(`tone="warn"`)로 읽힌다. 가는 선과 작은 문양에만 쓴다.
- **띠 위에 놓인 조작 요소의 초점 고리는 `--band-line`**이다(`outline-color`). 그 밖에는 `--focus`가 그대로 보인다.
- 새 면에 글을 올리면 `tests/a11y.test.ts`의 `PAIRS`에 그 짝을 더한다(시험은 적힌 짝만 계산한다).
- 어두운 판은 밝은 판을 뒤집은 것이 아니라 따로 정한 **달밤**이다: 바탕은 검정이 아닌 짙은 쪽빛, 글은 달빛 받은 옅은 푸른 흰색, 오른쪽 위에 달빛(`--glow`)이 번진다. `tokens.css`의 어두운 판 두 묶음은 값이 같아야 한다.

## 4. 꼴

- **모서리**: 카드 `--r-lg`(20px), 안쪽 상자·입력 `--r-md`(12px), 작은 것 `--r-sm`(8px), 단추·배지·띠·탭은 `--r-full`. 글이 두 줄이 될 수 있는 알약은 `--r-full` 대신 줄 높이의 반쯤 되는 값(예: `1.05rem`)을 준다(두 줄이 되어도 타원이 되지 않게).
- **테두리**: `1px solid var(--border)`. 결을 띤 상자는 그 결의 색을 30%쯤 섞는다. 왼쪽에만 굵은 막대를 두는 꼴은 쓰지 않는다.
- **그림자**: 카드는 `--shadow-1`, 묻는 창·펼침 메뉴는 `--shadow-2`, 띠는 `--shadow-band`. 그 밖의 그림자를 만들지 않는다.
- **띠의 금선**: 띠 안쪽 3px에 `1px solid var(--band-line)`을 `opacity: 0.5`쯤으로 두른다(`::after`, `pointer-events: none`). `Shell`의 `.link[aria-current='page']::after`가 기준이다.
- **높이를 정하지 않는다**(`min-height`만). 글이 두 줄이 되면 상자가 자란다. 0061의 약속 그대로다.
- **움직임**: 조작 요소의 `transition`은 색·테두리·그림자에만, 0.15초. 화면이 바뀔 때의 움직임은 두지 않는다. 움직이는 장식은 바탕의 꽃잎(`Petals`) 하나뿐이다(6장).

## 5. 글꼴

- 본문·라벨·숫자·단추: **Pretendard Variable**(`--font`).
- 화면 제목(`h1`), 이름, 로그인 카드, 맺음 글귀: **고운바탕**(`--font-display`, 400·700).
- 그 밖(구역 제목 `h2`, 소제목, 표, 입력)에는 명조를 쓰지 않는다. 작은 흰 글이 쪽빛 위에 놓이면 고딕이 읽기 쉽다.
- 두 글꼴은 빌드에 들어간다(`src/main.ts`에서 들여온다, 허가서 `public/licenses/`). 낱자 조각으로 나뉘어 있어 화면에 나온 글자의 조각만 받는다.

## 6. 문양

문양은 색이 없는 SVG 모양이고(`src/ui/motif/`), `tools/gen-motifs.mjs`가 만든다. 부품은 `mask`로 걸고 색은 토큰으로 칠한다. 그래서 밝은·어두운 판을 따르고, CSP(`style-src 'self'`, 인라인 스타일 없음)에도 걸리지 않는다.

```css
.x::before {
  content: '';
  background: var(--accent);
  -webkit-mask: url('./motif/blossom.svg') center / contain no-repeat;
  mask: url('./motif/blossom.svg') center / contain no-repeat;
  pointer-events: none;
}
```

| 문양 | 파일 | 쓰는 곳 |
| --- | --- | --- |
| 꽃(다섯 꽃잎) | `blossom.svg`, 아이콘 `blossom` | 이름 표식, 제목 아래 맺음 줄, 소제목 앞, 맺음 |
| 꽃잎 한 장 | `petal.svg` | 바탕에 흩날리는 꽃잎(`Petals`) |
| 치맛단 꽃무늬 | `hem.svg` | 사이드바·펼침 메뉴·로그인 바탕의 아래쪽 |

지킬 것:

- 장식은 **`::before`/`::after`나 `aria-hidden` 요소**로만 그리고 `pointer-events: none`을 준다. 넘치지 않게 놓인 상자에 `overflow: clip`을 둔다(가로 스크롤이 생기면 배치 검사가 잡는다).
- 꽃(`blossom`)은 꽃잎 하나가 위를 향해 위아래가 고르지 않다. 원 안에 놓았을 때 눈에 가운데로 보이게 0.8만큼 내려 그려 둔다(`tools/gen-motifs.mjs`의 `CENTER`, 아이콘과 파비콘도 같다).
- `forced-colors: active`와 인쇄에서는 장식을 지운다.
- 문양을 새로 그리거나 고치면 크게 그려서 눈으로 본다. 조잡하면 쓰지 않는다.
- 일하는 자리(카드 안, 표, 폼, 목록)에는 문양을 넣지 않는다. 예외는 소제목(`h3`) 앞의 작은 꽃 하나다.

### 흩날리는 꽃잎(`Petals`)

- 연하고 반투명한 꽃잎 열여덟 장이 위에서 아래로 천천히 떨어지며 흔들린다(한 장이 화면을 지나는 데 17~30초). 색은 `--drift`, 진하기는 `--drift-alpha`다.
- **카드와 글 뒤에만 그린다.** 틀의 빈 자리(화면 머리, 카드 사이, 본문 양옆)와 로그인 바탕에서 보인다. 글 위로 지나가지 않는다.
- 화면 높이만큼의 층이 스크롤을 따라 붙어 있다. 문서의 길이를 바꾸지 않고, 누를 수 없고, 보조 기술에 숨긴다.
- **움직임 줄이기를 켠 기기, 강제 색 모드, 인쇄에서는 그리지 않는다.**
- 꽃잎마다 다른 값(자리, 크기, 빠르기)은 부품의 스타일에 `:nth-child`로 적는다. 인라인 스타일을 쓰지 않는다(CSP).
- 배치 검사(`e2e/check.mjs`)는 움직임 줄이기로 잰다(잴 때마다 꽃잎 자리가 달라지지 않게). 켠 채로 재려면 `--motion`.

## 7. 부품의 모습

| 부품 | 모습 |
| --- | --- |
| `Shell` | 사이드바는 치마(흰 면에서 치맛단으로 번지고 아래에 흰 꽃). 지금 화면은 쪽빛 띠. 본문 위쪽은 하늘 번짐과 빛, 그 위로 꽃잎. 좁은 화면의 위 막대는 쪽빛 띠, 아래 막대의 지금 화면은 위쪽의 띠 한 토막 |
| `Page` | 제목은 명조. 아래에 꽃에서 흘러 옅어지는 금선. 화면의 동작 단추는 제목 옆 오른쪽(좁으면 금선 아래 오른쪽) |
| `Section` | 흰 카드. 제목(아이콘·곁글 포함)은 카드의 왼쪽 가장자리에서 나온 쪽빛 띠(오른쪽 끝만 둥글다). 그 구역의 배지·링크·단추는 띠와 같은 줄의 오른쪽에 놓인다. 살펴야 하는 구역은 띠와 테두리가 그 결의 옅은 색 |
| `Solo` | 하늘에서 치맛단까지의 바탕, 흩날리는 꽃잎과 치맛단의 흰 꽃. 카드 머리에 이름 표식·이름·글귀 |
| `Button` | 알약. 주된 단추는 쪽빛에 안쪽 옅은 선 |
| `Tabs` | 알약 꼴 홈 안의 알약들. 지금 칸은 쪽빛 띠(금선 포함). 한 줄로 두고, 가려진 칸이 있는 쪽 끝을 옅게 흐려 더 있음을 알린다 |
| `Stat` | 흰 타일(번짐 없음) |
| `Badge`, `Dot` | 알약, 결의 옅은 바탕 |
| `Callout` | 결의 옅은 바탕과 같은 결의 옅은 테두리. 굵은 왼쪽 막대 없음 |
| `Empty` | 옅은 면에 쪽빛 점선, 아이콘은 쪽빛 |
| `Item` | 앞 아이콘은 둥근 원(그림이면 `media`). 제목·아래 글·줄 아래 덧붙임이 같은 왼쪽 선에서 시작한다. 짧은 끝 요소 하나는 휴대폰 너비에서도 제목 옆에 남는다 |
| `Table` | 머리 줄은 옅은 면, 줄 사이는 옅은 실선, 가리킨 줄은 번짐 색. 숫자 칸은 오른쪽으로 맞춘다(`num`). 좁으면 줄마다 카드로 바뀌는데, 칸이 셋 이하인 표는 18rem 아래에서만 바뀐다(두 단 배치의 카드 안에서도 표로 남게) |
| `KV` | 이름은 흐리게, 값은 본문 색. 좁은 자리에서는 이름 칸을 줄여 짧은 값이 이름 옆에 남는다 |
| 소제목(`h3`) | 한 단 작고 흐린 이름표, 앞에 작은 금색 꽃. 구역 안에서 앞 묶음과 선으로 나뉜다 |
| `Progress` | 알약 꼴 홈, 채움은 쪽빛(`--accent`. 띠의 색은 어두운 판의 홈과 대비가 모자라 쓰지 않는다), 결이 있으면 그 색 |
| `Step` | 번호는 원. 지금 단계는 쪽빛 띠 색, 끝난 단계는 비취 |
| `Confirm` | 둥근 창(`--r-lg`, `--shadow-2`) |
| 입력(`field.css`) | `--r-md`, 가리키면 테두리가 쪽빛 |

## 8. 배치와 계층

- **구역 머리는 한 줄이다.** 띠(제목)와 그 구역의 배지·링크·단추가 같은 줄에 놓인다. 오른쪽 것이 길어 자리가 모자랄 때만 아래로 내려간다.
- **왼쪽 선은 하나다.** 카드 안의 글은 본문의 왼쪽 선에서, 목록 줄은 제목·아래 글·덧붙임이 같은 선에서 시작한다. 그림이나 아이콘은 그 선의 앞자리(`Item`의 `icon`·`media`)에 둔다.
- **세 단의 제목**: 화면 제목(명조, 큼) → 구역 제목(쪽빛 띠) → 소제목(작고 흐림, 꽃). 목록 줄의 제목은 본문 크기의 굵은 글이고 제목 단에 들지 않는다.
- **두 단 배치(`Columns`)는 높이가 비슷한 구역끼리만 묶는다.** 한 구역이 나머지를 합친 것보다 길면 그 구역을 밖으로 꺼내 전체 너비로 둔다(`Browser`의 사이트 위임). 순서는 상태·목록 먼저, 폼은 뒤다(휴대폰에서는 이 순서대로 한 줄로 쌓인다).
- **숫자는 표로, 오른쪽에 맞춘다.** 이름–값은 `KV`로 쓴다. 짧은 값을 이름 아래 줄로 내리지 않는다.

## 9. 고친 뒤 볼 것

```sh
cd web/admin
npx vitest run                       # 접근성(대비·고정 색), 기능·글 보존, 화면 규칙
npx svelte-check
e2e/run.sh --sets stress,full,alt --theme both --shots    # 가로 넘침·글자 겹침·CSP 위반, 스크린샷
```

모습을 고칠 때는 개발 서버로 바로 본다(운영 데몬을 가리키지 않는다).

```sh
LUCIA_UI_FIXTURE_ADDR=127.0.0.1:47890 cargo test -p luciad serve_ui_fixtures -- --ignored --nocapture   # 시험 데이터 서버
LUCIA_UI_DEV_PROXY=http://127.0.0.1:47890 npm run dev                                                   # http://127.0.0.1:5178
```

밝은 판·어두운 판, 1280px·360px 네 가지를 모두 본다. 한쪽 판에서만 예쁜 색은 토큰이 틀린 것이다.
