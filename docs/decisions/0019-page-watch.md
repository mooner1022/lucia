# 0019. 사전 체크 승격: 사람이 승인한 페이지 감시(선언형)

- 날짜: 2026-11-17
- 상태: 확정. 간격·문턱은 [제안]. 명세의 "사전 체크 승격 PR"과 방식이 다르다([제안], 아래 "명세와 다른 점").
- 결정 방식: 사용자 지시 "1, 3, 4 작업들 모두 순차적으로 진행해"의 5단계(도구화 사다리 3단계). 명세 §성공한 작업의 도구화 "주기적으로 반복되는 확인 작업(예: 특정 사이트의 공지 확인)은 데몬의 결정적 모듈로 승격해, 이후에는 모델 없이 돈다. 데몬 코드가 되므로 에이전트는 초안과 PR까지만 만들고, 반영은 사람이 리뷰한 뒤 한다."

## 결정

### 제안과 승인

- **제안**: Lucia가 `watch_propose(url, what, start_text?, end_text?, interval_minutes)`로 제안한다.
  - 사람이 시작한 일(채팅, 사람이 맡긴 작업)에서만 쓴다. 브리핑·후속 조치는 제안하지 못한다. 외부 글이 시킨 감시를 막으려는 것이다.
  - **주소**: 브라우저와 같은 출구 검사를 한다. http·https, 차단 목록, 사설·내부 주소 안 됨.
  - **값**: `what`은 한 줄 80자, 표지 글은 100자, 간격은 30~1440분이다.
  - 인젝션 검사를 한다. 감시는 20개까지다.
- **승인 카드**(`watch_review`, 3일):
  - 무엇, 주소(자르지 않음), 시작·끝 표지, 간격을 보인다.
  - [감시 시작]이면 감시한다. [하지 않기]나 만료면 지운다.
  - 감시는 정해진 주소로 계속 나가는 요청이라, 주소에 실린 글도 그 사이트로 간다. 카드에 그렇게 적었다.

### 확인(모델 없음)

- **사전 체크 소스**: 감시 하나가 사전 체크 소스 하나(`watch:<id>`, 공통 트레이트 `Source`)다. 새 소스는 모듈 하나를 추가한다는 명세 그대로다.
  - 매시 사전 체크 때 간격이 지난 것만 확인한다.
- **가져오기**: 브라우저 프록시와 같은 검사를 쓴다.
  - 이름을 한 번 풀어 모든 답을 검사하고, 그 IPv4 주소로만 연결한다(다시 풀지 않는다). 80·443만이다.
  - 넘겨주기는 따라가지 않고 매번 다시 검사한다(3번까지).
  - 20초, 2 MB까지이고, 글(text/·xml)만 받는다. 쿠키 없이 가져온다. 로그인이 필요한 페이지는 다루지 않는다.
- **구간**:
  - 스크립트·스타일을 뺀 보이는 글에서 시작 표지 뒤부터 끝 표지 앞까지만 본다. 구간 밖(광고, 시각)이 바뀌어도 변화가 아니다.
  - 표지 글을 못 찾으면 오류로 남긴다(관리 화면에 보인다).
- **변화**:
  - 첫 확인은 기준선만 잡는다.
  - 구간이 바뀌면 사전 체크의 "바뀐 것"이 된다. 요약과 구간 앞 600자가 들어가 브리핑이 다룬다.
  - 소식("감시 중인 …이 바뀌었습니다")으로도 쌓아 묶어 보낸다(결정 0015).
- **잡음 막기**: 확인할 때마다 세 번 이어 바뀌면 멈추고 소식으로 알린다. 매번 모델을 부르는 브리핑이 되지 않게 하려는 것이다.

### 관리 페이지(시스템 화면 "페이지 감시")

- 무엇, 주소, 상태, 간격, 구간, 마지막 확인, 오류를 보인다.
- 조작: 멈추기, 다시 켜기(기준선부터 다시), 지우기.

## 명세와 다른 점

- 명세는 감시를 데몬 코드 모듈로 바꾸는 초안과 PR, 사람의 리뷰다.
- 지금은 **선언형 감시**(주소와 구간을 데이터로, 모듈은 하나)를 사람이 카드에서 승인한다. 까닭:
  - 이 레포에는 원격이 없다(`git remote -v`가 비었다). 상주 에이전트에게는 코드 도구가 없다.
  - 레포 작업 트리는 VM에 마운트된 운영 트리다.
  - 감시 하나하나가 코드가 아니라 데이터라서, 사람의 리뷰는 카드에서 주소·구간·간격을 보는 것으로 충분하다.
- 코드가 필요한 확인(로그인 사이트의 결정적 스크래퍼 등)은 6단계(개발 위임, 승인을 거치는 git push)가 생긴 뒤 PR 방식으로 한다.

## 확인(2026-11-17)

- **시험**:
  - 구간 뽑기: 스크립트·스타일 빼기, 표지 사이, 표지 없음.
  - 기준선 → 그대로(구간 밖 변화) → 바뀜.
  - 제안:
    - 사설 주소·차단 목록·짧은 간격은 거절한다.
    - 브리핑은 제안하지 못한다.
    - 채팅 제안은 승인 대기와 카드다(주소 그대로).
  - 카드: [감시 시작] → 감시, [하지 않기] → 지움.
  - 엔진(사전 체크):
    - 기준선 → 변화 1건과 소식.
    - 세 번 이어 바뀌면 멈춤과 소식. 모델 0번.
    - 멈춘 감시는 소스가 되지 않는다.
  - 저장소: 상태와 잡음 멈춤.
- **실제 네트워크**(`real_fetch_goes_through_the_checks`, 수동):
  - 공개 페이지를 가져온다.
  - 사설 주소(192.168.0.1)와 관리 페이지(127.0.0.1:8780)는 막는다.
  - http → https 넘겨주기는 검사하며 따라간다.
- **실제로 아직 안 본 것**: 실제 모델이 감시를 제안하는 것, 운영 Discord 카드, 운영에서 감시가 브리핑에 들어가는 것.
