# 0040. 권한 모드: 엄격 · 기본 · 해제

- 날짜: 2026-11-18
- 상태: 확정. 엄격 모드의 항목은 [제안]이다(사용자가 정하지 않았다). **해제 모드와 금지 동작은 결정 0059로 바뀌었다**(메일 발송·Discord 글·브라우저의 글 등록은 해제에서도 카드, 금지 동작은 승인 카드나 사람 전용으로).
- 결정 방식: 사용자 지시 "아예 권한 체계를 단계로 분리하고 이를 선택할 수 있도록 바꾸자. 엄격해야 할 때와 널널해도 될 때를 내가 선택하여 적용할 수 있도록. 대시보드와 디스코드 슬래시 명령에서 선택할 수 있도록 하고, 지금 모드를 기본값, 지금보다 엄격한 모드, 완전히 해제하는 모드 세 가지로 나눠."
  - 사용자 답:
    - 해제는 "승인 카드만 없앰": 금지 동작은 그대로 막는다.
    - 해제는 "대화 중에만" 적용한다.
    - 자동 복귀는 "없음"이다.
  - Advisor 설계 검토를 반영했다(아래).

## 결정

### 모드(`crate::security`, 설정 `security.mode`)

- **기본**: 지금까지의 규칙이다.
- **엄격**: 모든 실행에서 더 묻는다 [제안].
  - 브라우저: 링크 이동·펼치기·탭과 Enter·Space 아닌 키 말고는, 누르기·글 넣기·Enter·Space를 승인 카드로 묻는다.
  - 사이트 위임의 "로그인"·"동작"을 쓰지 않는다. 읽기 위임은 그대로다.
    - 부작용: 로그인 게시판 감시의 자동 재로그인과, 위임으로 하던 묻지 않는 동작이 멈춘다.
  - 캘린더: 참석자 없는 내 일정도 만들기·고치기를 카드로 묻는다. 카드를 올릴 수 없는 사람 없는 실행(브리핑 등)은 일정을 쓰지 못한다.
  - 나가는 글 검사(결정 0029)를 "막기"로 본다.
  - 반복 루틴은 새로 만들거나 고치면 모두 승인 카드를 거친다.
  - 사람 없는 실행의 기억 쓰기는 갈래와 상관없이 보류 카드로 묻는다. 하루 정리는 그대로다.
- **해제**: 사람이 대화 중인 실행(`grants.human`)에서만 적용한다.
  - 일회성 외부 쓰기를 카드 없이 한다. 대상은 허용 목록이다.
    - 메일 발송, Discord 글 올리기·서버 관리, 캘린더 쓰기·지우기: 요청을 만들 때 "카드 없이" 표시를 남기면, 승인 데스크가 누르지 않아도 실행하고 DM에 버튼 없는 닫힌 카드("🔓 권한 모드가 해제라 묻지 않고 했습니다")로 남긴다.
    - 브라우저 동작: 판정 지점에서 승인을 그냥으로 바꾸고, 사람이 승인한 동작처럼 한다(확인 대화상자를 받아들인다). 활동 기록은 `browser_open_mode`다. 데스크를 거치지 않으니 Enter마다 기록 카드가 쌓이지 않는다. 나가는 글 검사의 "막기"로 생긴 승인도 건너뛴다.
    - 기록 카드가 올라가지 못하면 글로라도 DM에 남긴다(해제에서는 이 기록이 사용자가 볼 유일한 흔적이다). Discord는 버튼이 없으면 버튼 줄을 넣지 않고 보낸다.
    - 저장된 로그인으로 다시 로그인할 때 묻지 않는다.
  - 그대로 두는 것:
    - 사람 없는 실행(브리핑·후속 조치·루틴·신호·작업 세션·코드 실행)은 기본 규칙이다.
    - 금지 동작(결제·주문·송금·탈퇴·비밀번호 바꾸기·로그아웃·파일 올리기·로그인 폼 직접 입력)은 하지 않는다.
    - 모드가 끝나도 남는 권한(사이트 위임, 루틴·감시·스킬 승인)은 카드로 묻는다. 해제가 사람 없는 실행에 권한을 넘기지 않게 하려는 것이다.
    - 인젝션 보류, 비밀, VM 격리, 네트워크 제한.
- **판정 시점**: "카드 없이"는 요청을 만들 때 한 번 정해 저장소의 타입 있는 칸(`approvals.auto`, 마이그레이션 0023)에 남긴다. 데스크는 그대로 따른다. 모델 인자가 섞일 수 있는 payload에는 두지 않는다.
  - 도구 답도 같은 판정을 쓴다("카드 없이 데몬이 바로 한다. 사용자에게 카드를 누르라고 하지 않는다").
- **기본값**: 설정이 없거나 깨졌거나 읽지 못하면 기본이다(해제로 떨어지지 않는다).
- 이미 떠 있는 카드에는 소급하지 않는다. 자동으로 돌아가지 않는다(사용자 선택).

### 바꾸는 길(둘뿐, 모델 도구 없음)

- **관리 페이지 개요 맨 위 "권한 모드"**: 세 모드와 설명, 모드마다 달라지는 것, [바꾸기]가 있다(로그인·CSRF).
- **Discord `/권한 [모드]`**:
  - 버튼 누름과 따로, 어댑터의 명령 분기만 만드는 `SlashCommand`다(앱 게이트웨이의 누름 통로로는 흉내 낼 수 없다).
  - 연결(Ready)될 때마다 전역 명령을 통째로 덮어써 등록한다.
  - 데스크가 소유자인지 확인한다. 소유자가 아니면 본인에게만 보이는 거절로 답한다.
  - 2.5초 안에 답하고, 늦으면 어댑터가 시간 초과로 답한다. 명령은 데스크 줄 밖에서 바로 처리하고, 답 받는 쪽이 이미 떠난 명령(시간 초과로 답함)은 적용하지 않는다(실패로 알고 있는데 모드가 바뀌지 않게).
  - 옵션이 없으면 지금 모드와 설명을 보인다.
  - 서버에서 부르면 답은 본인에게만 보이고, 바꾼 기록은 DM에 남긴다.
- 바꿀 때마다 활동 기록(`security_mode`)과 Discord 알림을 남긴다.

## Advisor 검토에서 반영한 것

- 해제의 자동 처리를 일회성 허용 목록으로 좁혔다. 지속 권한(위임·루틴·감시·스킬)은 카드다.
- 자동 판정을 요청 때 타입 있는 칸으로 고정했고, 도구 답이 같은 판정을 쓴다.
- 명령을 버튼 누름 문자열에 얹지 않았다. 별도 변형이고, 소유자 확인과 비소유자 거절을 둔다.
  - 명령 구조는 설치된 twilight-model 0.18 소스로 확인했다. 한글 이름 "권한"은 twilight-validate로 시험했다.
- 브라우저는 판정 지점에서 모드를 적용한다(`classify*`는 그대로, `gated`에서 조정).

- 배포 전 두 번째 검토: 늦은 명령을 적용하지 않기, 기록 카드 실패 때 글로 남기기, 재로그인 기록 문구("사람에게 묻지 않고: 로그인 위임 / 권한 모드 해제"), 대시보드·루틴 시험.

## 시험

- **모드**: 없거나 깨지면 기본. 해제의 자동은 사람이 대화 중 + 일회성 종류일 때만이다(사람 없음·지속 권한·엄격이면 카드). 바꾸면 활동 기록.
- **데스크**: "카드 없이" 표시가 있는 메일 요청은 누르지 않아도 보내고 버튼 없는 닫힌 카드를 남긴다. 표시가 없으면 카드.
- **명령**:
  - 소유자가 아니면 거절하고 바꾸지 않는다.
  - 옵션이 없으면 지금 모드를 보이고, "해제"면 바꾼다. 모르는 값은 본인에게만 답한다.
  - 어댑터: 등록 명령이 Discord 규칙을 지키고(한글 이름 포함), 답을 전달하며, 늦으면 시간 초과로 답한다.
- **브라우저**:
  - 해제 + 대화 중이면 POST 제출을 카드 없이 사람이 승인한 것처럼 한다.
  - 해제여도 로그아웃은 금지, 사람 없는 실행은 카드다.
  - 엄격이면 링크 이동은 그냥, 글 넣기는 카드다.
- **기억**: 엄격이면 사람 없는 실행의 주제 쓰기도 보류하고, 대화 중은 그대로다.
- **루틴**: 엄격이면 스크립트 없는 루틴도 승인 대기로 만든다(기본이면 바로 켠다).
- **관리 페이지**: 로그인·CSRF 없이는 못 바꾸고, 모르는 값은 거절하며, 바꾸면 활동 기록이 남고 개요에 지금 모드가 보인다.
- **늦은 명령**: 답 받는 쪽이 먼저 떠난 `/권한`은 모드를 바꾸지 않는다.
- **아직 못 본 것**:
  - 실제 Discord에서 `/권한`을 눌러 보는 것(등록은 배포 뒤 첫 연결에서 된다).
  - 운영에서 해제 모드로 메일·글 올리기와 기록 카드.
  - 도구별 "카드 없이" 표시 배선(메일·Discord·캘린더 도구가 해제 + 대화 중일 때만 붙이는지)은 판정 함수와 데스크 쪽만 시험했다.
  - 엄격의 캘린더 카드, 감시의 자동 재로그인 멈춤, 나가는 글 막기는 판정 줄만 바꿨고 따로 시험하지 않았다.

## 후속(2026-11-19)

전용 앱(결정 0043)도 `call command {name: "권한"}`으로 같은 처리기를 부른다. 보기는 누구나 되지만, **바꾸기는 관리 페이지에서 `security_mode` 범위를 준 토큰만** 된다(기본 없음). 앱에서 바꾸면 알림 대화에도 남는다. 위 "바꾸는 길은 관리 페이지와 소유자의 Discord 명령 둘뿐"은 이 범위만큼 넓어졌다.
